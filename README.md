# 해양경찰 법령정보센터 (KCG Law Information Center)

> **해양경찰 소관 법령 및 훈령·예규·고시를 로컬 PC에서 손쉽게 관리하고 전문 검색 및 열람할 수 있는 독립형 법령 정보 웹 애플리케이션**

---

## 📌 프로젝트 소개
'해양경찰 법령정보센터'는 국가법령정보센터 수준의 법령 열람 편의성을 로컬 단일 PC 환경에서 제공하기 위해 기획·개발된 웹 애플리케이션입니다.  
사내 폐쇄망이나 독립 업무 환경에서도 해양경찰청 소속 공무원 및 관리자가 법령 문서를 직접 등록·보관하고, 국가법령정보센터 특유의 **2열 본문 뷰어(좌측 목차 트리 + 우측 본문 조문 스크롤 연동)** 및 **키워드 전문 검색**을 지원합니다.

---

## 🎨 디자인 테마
본 프로젝트는 해양경찰의 신뢰성과 전문성을 상징하는 지정 컬러 팔레트를 바탕으로 구축되었습니다.

- **Primary (Deep Navy / `#2A5078`)**: 상단 글로벌 헤더, 메인 법령 제명, 핵심 액션 버튼
- **Secondary (Steel Blue / `#6587A5`)**: 조문 번호(제1조 등), 링크 텍스트, 뱃지, 호버 효과
- **Background Subtle (Ice Blue / `#DBE4EB`)**: 사이드바 배경, 카드 테두리, 배경 구분선
- **Muted Gray (Slate Gray / `#848996`)**: 발령번호, 시행일자, 소관부서 메타정보 보조 텍스트
- **White (`#FFFFFF`)**: 법령 본문 뷰어 용지 배경 및 입력 필드 배경

## 🌟 핵심 기능
1. **메인 홈 및 통합 검색**
   - 웹앱 상단 로고 및 직관적인 메뉴 네비게이션 (`법령`, `행정규칙`)
   - 키워드, 조문 내용, 법령명 통합 검색 기능
   - 주요 법령 및 최근 행정규칙 바로가기
2. **법령 / 행정규칙 목록 화면**
   - 카테고리별(법률/대통령령/부령 및 훈령/예규/고시) 목록 분리 조회
   - **홈 화면으로 돌아가기(←)** 네비게이션 제공
   - 목록 내 즉각 필터링 및 정렬
3. **국가법령정보센터 스타일 2열 법령 뷰어 (새 창)**
   - 목록/검색 결과 클릭 시 전용 뷰어가 **새 창(팝업/새 탭)**으로 실행
   - **좌측 사이드바**: 본문(장·절·조문 계층), 부칙, 별표·서식 목차 트리 제공 (클릭 시 해당 위치로 부드러운 스크롤 이동)
   - **우측 메인 본문**: 공식 법령 서식에 맞춘 조/항/호 인덴트 레이아웃, 조문 앵커 링크
   - **뷰어 툴바**: 본문 내 단어 검색(노란색 강조), 글자 크기 확대/축소, 인쇄/PDF 저장 기능
4. **관리자 화면 (수동 업로드 및 Open API 자동 수집)**
   - 법령/행정규칙 파일의 수동 업로드 (텍스트, 마크다운, JSON, PDF 등 지원)
   - **국가법령정보센터 Open API 자동 동기화**: 사용자 인증키(`kcg_laws_20261018001`)를 연동하여 해양경찰 법령·행정규칙 및 별표·서식 한글/PDF 원본 자동 수집
   - 로컬 PC 내 물리 디렉터리(`data/storage/laws`, `data/storage/rules`)에 안전한 영구 보관
   - 업로드/수집 즉시 조문 구조 자동 파싱 및 SQLite 로컬 검색 인덱스 갱신

## 🚀 빠른 시작 (Quick Start)
### 필수 조건
- Windows 환경 (Python 3.12 이상 이미 설치 확인됨)
- 웹 브라우저 (Chrome, Edge 등)

### 실행 방법
1. 프로젝트 루트 폴더의 `start.bat` 파일을 더블클릭합니다.
2. 필요한 가벼운 패키지(`fastapi`, `uvicorn`, `python-multipart`)가 자동으로 준비되며, 백엔드 서버가 구동됩니다.
3. 기본 웹 브라우저가 자동으로 실행되며 `http://127.0.0.1:8000`으로 접속됩니다.
